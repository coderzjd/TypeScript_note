| #   | JS 语法                    | 类型世界新身份                        | 编译期作用                           | 备注（与运行时差别的关键点）                                      |                |                                                  |
| --- | -------------------------- | ------------------------------------- | ------------------------------------ | ----------------------------------------------------------------- | -------------- | ------------------------------------------------ |
| 1   | `+ - * /` 等**算术运算符** | 数值运算型（`+`、`-`、`/`、`*`、`%`） | 仅对**字面量**生效，得到**新字面量** | 不会真的做 IEEE 754 计算，只是**常量折叠**；`number` 变量不能参与 |                |                                                  |
| 2   | `&&` \`                    |                                       | ` `!\`                               | 布尔运算符                                                        | 字面量布尔折叠 | `boolean` 变量同样不参与，仅 `true/false` 字面量 |
| 3   | `===` `!==`                | 字面量恒等比较                        | 条件类型分支                         | 对 `string`/`number`/`boolean` 字面量做**精确相等**判断           |                |                                                  |
| 4   | `in` 运算符                | 属性存在性检查                        | `K in keyof T`                       | 左边必须是**字面量字符串**，右边是对象类型                        |                |                                                  |
| 5   | `for...in` 循环            | 映射类型 `[K in keyof T]`             | 结构化循环，生成新对象               | 不是运行时遍历，而是**一次性展开**                                |                |                                                  |
| 6   | `as` 类型断言              | 模板字面量重命名 + 类型断言           | 改变键名或强制类型                   | 同关键字，两种场景，**语义分离**                                  |                |                                                  |
| 7   | `instanceof`               | 弃用（无穿越）                        | —                                    | 类型世界**没有原型链**，故未引入                                  |                |                                                  |
| 8   | 数组/对象**解构**          | 元组 `infer` 解构                     | `...infer Rest`、对象 `infer {a}`    | 仅用于**模式匹配**，不会生成运行时变量                            |                |                                                  |
| 9   | 展开运算符 `...`           | 元组展开、`&` 交叉                    | `[...A, ...B]`、`A & B`              | 数组展开=拼接，对象展开=交叉                                      |                |                                                  |
| 10  | 三目 `?:`                  | 条件类型 `extends ? :`                | 同形不同层                           | 运行时值 → JS 三目；编译期类型 → 条件类型                         |                |                                                  |
| 11  | `typeof` 运算符            | **类型查询** `typeof x`               | 把**值空间**类型化                   | 与 JS `typeof` 返回字符串**完全脱钩**                             |                |                                                  |
| 12  | `keyof` 运算符             | —                                     | 专属类型世界，无 JS 对应             | 反射对象键并生成联合                                              |                |                                                  |
| 13  | 模板字符串 `` `...` ``     | 模板字面量类型                        | 模式匹配+字面量拼接                  | **不执行表达式**，仅做**词法匹配**                                |                |                                                  |
